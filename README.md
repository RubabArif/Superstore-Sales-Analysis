Superstore Sales Analysis
Project Overview
This project focuses on analyzing Superstore sales data to identify sales trends, product performance, regional performance, and profitability.
Tools and Technologies
•	Python (Pandas, NumPy)
•	Microsoft Excel
•	MySQL
•	Power BI
Project Structure
•	Python: Data cleaning and analysis
•	Excel: Data analysis and reporting
•	SQL: Database queries and analysis
•	Power BI: Interactive sales dashboard
•	Dataset: Cleaned Superstore dataset
Key Business Questions
•	Which regions generate the highest sales?
•	Which product categories perform best?
•	Which products generate the highest profit?
•	What are the sales trends over time?
•	How do sales and profit vary across regions?
Skills Demonstrated
•	Data cleaning
•	Exploratory Data Analysis (EDA)
•	SQL querying
•	Excel analysis
•	Data visualization
•	Business intelligence and dashboard development
